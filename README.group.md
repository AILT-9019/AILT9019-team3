# AILT9019 Group Project — Historical Overview

This file records the original project direction: extract course tasks and deadlines, store structured results, and produce a weekly academic brief with priorities and potential conflicts.

Those goals are not a statement that every feature is implemented. Current setup and usage are documented in `README.md`; product status and differences from the proposal are documented in `实现计划.md`.

The tool is an organizational aid. It does not access university accounts, submit coursework, contact instructors or make academic decisions.
